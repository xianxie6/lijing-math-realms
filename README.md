# 理境 · Mathematical Realms

一个以暮蓝自然研究手稿为视觉语言、用交互图形解释深奥数学概念的数字展厅。

## 在线体验

[https://lijing-math-realms.xiande.chatgpt.site](https://lijing-math-realms.xiande.chatgpt.site)

## 已收录理论

1. 三维 Kakeya 集
2. 黎曼猜想
3. 哥德尔不完备定理
4. 曼德博集合
5. 庞加莱猜想
6. P 与 NP
7. 巴拿赫–塔斯基悖论
8. 傅里叶变换
9. 康托尔无穷
10. 莫比乌斯环与克莱因瓶
11. 纳维–斯托克斯方程

每一章包含研究手稿、分步概念解释、数学公式和独立的 Three.js 交互场景。

## 技术栈

- React + Vite
- Three.js / React Three Fiber
- KaTeX
- CSS 响应式排版

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 说明

这是概念可视化与数学科普项目。交互场景用于建立直觉，不替代正式定义、完整证明或专业课程。
